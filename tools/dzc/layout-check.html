Layout check — each frame is a REAL viewport width

Built because resize_window reports success while window.innerWidth stays at the desktop width, so any responsive check run against it is measuring the wrong viewport. An iframe's width is genuinely the width its content lays out against.

Every ROUTE, not just the landing screen.
